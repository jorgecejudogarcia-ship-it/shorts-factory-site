# Shorts Factory Privacy Policy

Last updated: 20 October 2026.

Shorts Factory is a privately operated application used to create and upload videos to a YouTube channel controlled by its owner.

With the owner's authorization, it uses the YouTube API to upload videos, titles, descriptions and publication settings. It does not access Gmail or unrelated Google services.

OAuth credentials are intended to be stored in encrypted GitHub Actions secrets in a private repository, and are not shared publicly.

The application does not sell Google user data. The operator can revoke authorization through Google Account settings and delete stored credentials.

Use of Google API data is subject to the Google API Services User Data Policy (https://developers.google.com/terms/api-services-user-data-policy), including applicable Limited Use requirements.

For privacy inquiries, contact the operator using the support email provided on the Google OAuth consent screen.
